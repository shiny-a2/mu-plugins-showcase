# Cautious competitor activity estimates

The competitor dashboard now holds a whole-brand stock disappearance for review, including brands represented by only a few observed models. It no longer presents that grouped change as several possible sales. Individual stock changes remain labelled as uncertain signals; public listings cannot prove a rival's orders.

Historical dashboard aggregates were reconciled against saved observations with protected backups and readback checks. Focused calculation and cache tests passed, and the published runtime matched the reviewed source. Authenticated visual acceptance of the management screen remains pending.
