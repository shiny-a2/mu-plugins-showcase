# Counter sale announcements

Branch accounting imports now provide a notification when a sale is recorded or its payment details are corrected. Each branch has its own feed. The invoice number and stored totals remain consistent across imports, so the management bot can update the same receipt. A verified catalogue match supplies a product photo where one exists.

Isolated WordPress, WooCommerce and MariaDB checks covered first import, unchanged re-import, corrected payments, line photos, invoice ownership and the notification query index. The installed feed was checked with both branch connections. The rollout did not replay historical sales.
