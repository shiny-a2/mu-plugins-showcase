# Reviewing corrections to counter sales

A corrected accounting file now gives the branch manager a comparison of the original sale and the proposed changes. The manager can inspect the items, quantities, total and payment split, along with the effect on customer points and the branch's current stock. Approval updates the original receipt. An unchanged upload produces no duplicate sale or award.

The review accounts for what happened after the purchase. If the branch has recounted a watch, only the difference between the approved sale quantities changes the current count. If purchase points have already been spent, the manager sees the shortage and how much can be recovered immediately. Future available points cover the remaining balance.

The isolated commerce tests exercised actual spreadsheet uploads, unauthorized and stale decisions, repeat approvals, changed payment splits, previously spent points and a later stock count. A simulated failure between two product updates rolled back the correction. The manager interface was checked on phones and desktop in both themes.
