# Reuse daily watch evidence without changing the report

Adjacent daily comparisons reuse each prepared observation within the report request. The bounded cache keeps two observations per source. Raw shelf data and price supplements remain available to their existing readers, while contact-only offers, accessories, brand withdrawals and suspicious price-scale changes retain their existing treatment.

Validation passed 32 isolated PHP scripts. A read-only full-report comparison across 44 sources retained the exact result digest and reduced product checks from 1,565,613 to 1,141,496. Overall runtime varied with host and database caching; these diagnostic runs do not establish a whole-page speed guarantee. Large fully cold reports remain costly.

No presentation asset, database schema, collector or external API behavior changed. Release verification checks source hashes, the reported workspace version, authorized access and guest denial without creating messages, invoices or new market captures.
