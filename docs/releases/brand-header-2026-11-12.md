# Supplied brand logo in the storefront header — 12 November 2026

The storefront header now uses the supplied, transparent brand artwork in its desktop and mobile layouts. Its light and dark appearances use separate lossless assets, preserving the fine strokes of the original mark. The change stays within the existing header and theme behavior.

The release also refreshed the cached header output after the media change, so anonymous visitors receive the current artwork. A backup and rollback point were retained.

Validation: the live home page rendered the new logo at 390 and 1440 pixel widths in both themes. The mobile menu and theme control were exercised, the desktop theme control was exercised, and no horizontal overflow was observed. No purchase or account action was performed.
