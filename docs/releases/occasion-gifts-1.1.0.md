# Birthday and anniversary gift preparation

Customers can see how much an occasion gift is worth, when it expires and how to use it on one simple page. Birthday and wedding gifts follow the same purchase-based discount tiers, become available a week before the event and expire at the end of the following day. One reminder replaces the earlier sequence of messages.

New gift codes are short and traceable internally. Existing unused codes can retain their original text while moving to the new terms. Coupons remain tied to the intended customer, and conversion has a guarded recovery path. The gift page includes a countdown, code copying, concise instructions and a route back to the store. The account panel links to the same explanation.

The contact hub has corrected branch telephone attribution, a direct branch shortcut and a rules tile. Gift and service terms are aligned across the relevant pages. Annual credit reminders move to ten days before year-end, with paid funds kept separate from promotional expiry. Earned-points messages remain paused.

Validation uses isolated WordPress, WooCommerce and MariaDB records. Checks cover discount boundaries, date rollover, customer access, concurrent issuance, interrupted writes, order recalculation and conversion recovery. Interactive browser checks cover mobile and desktop layouts in both themes, keyboard focus, copying, countdown expiry and reduced motion. No real customer message or transaction was created for testing.

This is a prepared candidate, not an installed release. Production installation, messaging-provider template confirmation, live checkout and live page rendering remain separate verification steps.
