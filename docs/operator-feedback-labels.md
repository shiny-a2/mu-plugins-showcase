# Evidence-based customer feedback labels

**Update — 20 October 2026**

An operator dashboard previously inferred a customer's mood from operational facts such as purchases and failed payments. Those facts do not establish how the customer feels and can produce misleading labels.

The dashboard now uses recent, explicit feedback notes or a customer's own rating. When neither exists, it shows an unknown state instead of guessing. Operators can expand the label to see its basis. A management summary uses the same classification so the two views remain consistent.

The update includes regression checks for negated phrases, changing feedback over time and old records, plus light/dark mobile and desktop visual checks. It does not expose customer records or implementation details.
