# Country-gate browser passes

A country-limited storefront may still need a named overseas stakeholder to inspect its public pages without maintaining a WordPress session. Residential addresses can change, while opening an ISP range would admit unrelated subscribers.

The private integration accepts exact operational IP entries and issues the existing signed, HTTP-only public-view cookie on the first trusted visit. That cookie keeps the same browser working after a residential address change. It is read only by the country gate and does not create a WordPress login, role or administrative capability.

Personal addresses stay outside source control and this showcase. CIDR entries are rejected. Automated coverage verifies exact matching, rejection of an adjacent address, signed-cookie issuance, access after an address change, existing crawler/path boundaries, and the light/dark mobile/desktop denial presentation.
