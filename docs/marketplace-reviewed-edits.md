# Marketplace edit review integration

Seller requests to change listing details now connect to the repair team's ticket inbox. Staff can open a comparison, approve changes or reject them with a reason. Seller summaries distinguish their own pending requests from new staff replies.

This release improves accountability and avoids publishing unreviewed changes. Responsive forms cover mobile/desktop and both color themes. Authorization, duplicate requests, stale proposals and transaction rollback were tested with synthetic data. No customer content or credentials are included here.
